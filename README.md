# 你和 Crush 的 Match 程度

一个单文件、纯前端的情感匹配测试网页。打开 `index.html` 就能用，不需要服务器、不需要数据库。

## 怎么打开

- Windows：双击 `index.html`，用 Chrome / Edge 打开。
- 手机预览：把文件夹部署成 https 链接后，用手机浏览器打开。

## 怎么变成可以发小红书的链接（3 分钟）

### 方案 A：Netlify Drop（最简单，不用命令行）
1. 打开 https://app.netlify.com/drop
2. 把整个 `crush-match` 文件夹拖进去
3. 等几秒，会得到一个 `https://xxxx.netlify.app` 的链接
4. 把这个链接放到小红书群聊/私信/主页，不要放正文

### 方案 B：GitHub Pages
1. 新建一个仓库，把 `index.html` 上传
2. Settings → Pages → Deploy from a branch → main / root
3. 得到 `https://你的用户名.github.io/仓库名/`

### 方案 C：Vercel
1. 安装 Node 后，在文件夹里执行 `npx vercel`
2. 按提示登录、部署，得到 https 链接

> 本地 `file://` 打开时，“复制结果链接”复制的是本地路径，不能直接发给别人；部署成 https 后才能当公网链接用。

## 页面流程

1. 第 1 页：选你的 MBTI + 星座（必填）
2. 第 2 页：选对方的 MBTI 或星座（至少一个，都填更准）
3. 第 3 页：12 道情感/心理情境题
4. 第 4 页：匹配总分 + 六维分析 + 高光/雷区 + 相处建议 + 分享卡

## 结果怎么算

- MBTI：E/I、S/N、T/F、J/P 四组维度的互补/相似度 + 常见高匹配组合加成
- 星座：火/土/风/水四元素、对宫、常见舒适组合
- 题目：情感共鸣、沟通模式、冲突修复、安全感、生活节奏、长期潜力 6 个维度
- 总分：题目 55% + MBTI/星座 45%（只填一个时自动调整权重）
- 结果仅供娱乐，不构成心理诊断

## 分享链接

结果页的“复制结果链接”会生成类似：

```
https://你的域名/?a=ENFP&z1=leo&b=INTJ&z2=aries&ans=321321321321
```

打开这个链接会直接还原同一份结果，适合发给朋友或让对方“测同款”。

## 想改内容

## 注意

- 不使用真实明星/剧照；头像和封面建议用原创 AI 角色。
- 不要在页面里收集真实姓名、手机号、身份证等敏感信息。
- 娱乐向测试，避免写成“心理诊断/命理预测”。
